# VU0 byte VMA 0x268: bounded static numerical evidence

This evidence accompanies the experimental model in `tools/vu/`. It contains numeric test output, exact source-span/LOI metadata, and Jev receipts. It deliberately excludes a full assembly listing, full decompiler output, or game payload bytes.

The PAL executable identity is SHA-256 `216711210898aee296eed73d0776e7f733bac04c334002683bce769c86beea95`. `parse_overlays` maps overlay 7 to VMA 0 at file offset `1162480`; the exact pair span `[77,102)` starts at `1163096`, is 200 bytes, and has SHA-256 `24fbedaf59f41ea50e1f3507e7ca7a2ad15642e22c7a05b3cd955576c4b83611`. The guard checks raw LOI payload words and the model bit table.

The host-side binary32 model uses exact raw LOI bits, rounds caller test values once to binary32 as QMTC2 payloads, then applies a toward-zero approximation only to arithmetic. Over 20,001 samples on `[0,2π]`, max absolute differences from host libm were `9.381821246406963e-7` (x vs sine) and `8.022761451842442e-7` (y vs cosine). Over `[-10,10]` the differences were `2.0470653239734737e-6` and `1.4899542371549224e-6`; over `[-100,100]`, `1.7534069339519842e-5` and `1.3138062233630787e-5`. Separate checks include 10,000 deterministic inputs, 51 quarter-turn boundary probes, lane invariance, a swapped-lane negative control, and a nearest-even rounding negative control.

These are static and host-model results only. They do not establish original programmer intent, arbitrary-input limits, exact PS2 silicon rounding, VU pipeline/flag/exception behavior, complete caller state, or runtime equivalence. Jev review receipts are advisory: the model review returned `review` with test-gap confidence limiting the result; the final combined promotion review escalated at safe-to-apply 0.62 because blast-radius confidence was low. An independent code/test inspection confirmed fixed-root path resolution, fail-closed identity/mapping/span/LOI checks, model-bit equality, and synthetic mutations for each guard seam. The deterministic checks passed; promotion does not imply hardware validation. The raw-byte and mutation-fixture tests remain the deterministic checks. Earlier wrong-load probes and their Jev receipts remain preserved as superseded in `vu268-superseded-probes-disposition.json` and the task scratch directory.

Reproduce with `python3 tools/vu/vu268_reference.py`, `python3 tools/vu/vu268_source_guard.py`, and `python3 -m unittest tools.test_vu0_reference` from the repository root.
