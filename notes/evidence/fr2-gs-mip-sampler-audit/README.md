# Public CPU sampler fixed-LOD audit

The pinned public PS2Recomp CPU backend samples the TEX0 base plane in six authored fixed-LOD cases, including configurations that specify mip levels1 and2. The experiment uses constant-color CT32 planes of8×8,4×4, and2×2 texels at distinct block bases32,64, and96. Two coordinate modes, UV and ST, draw four pixels into CPU VRAM. LCM1, MXL2, MMIN2, MTBA0 and signed4-fractional-bit K values0,16,32 specify fixedLOD0,1,2; filtering is point sampling. All six unredirected draws produce the level0 red plane. Four controls redirect TEX0 to the green/blue planes and read those colors correctly.
