# Two bounded dispatch reconstructions

`VerifiedDispatchPairOverride.java` reconstructs two PAL computed dispatches at `001fbe48` and `001161a8` in an isolated, read-only Ghidra project. It pins the ELF, patched native decompiler, Java source, native patch, baseline manifest, raw selector/table bytes, and saved entry set. The script restricts decoding to the exact target interval with automatic analysis and flow following disabled. All initialized memory and defined data must remain unchanged.

The positive run added exactly 29 instructions to the global listing (116 bytes). Function bodies gained 36 instructions (144 bytes), because seven instructions were already decoded and unowned. The bodies grew from 232 to 368 bytes and from 968 to 976 bytes. The original 3,837 saved entry set was unchanged. The deliberate permutation control changes the first dispatch's C hash while leaving the second stable; the independent reproducibility receipt records the two modes and their immutable paths/hashes.

The root combined run applied the dispatch pair, then the existing singleton `0017f510` override, then the full C/inventory/coverage exporters in one read-only process. It generated all 3,837 saved functions with zero failures. The decompilation artifact verifier passed. Exactly two C files changed relative to the previous singleton-guarded export, at the two expected dispatch entries; the singleton C was unchanged. Warning comments decreased from 608 to 606.

Physical saved-function instruction coverage increased from 941,700 to 941,844 bytes out of 1,247,328 executable bytes. The remaining 305,484 bytes outside saved function instruction ranges and the separately excluded 13,584 placeholder bytes keep the code-discovery inventory incomplete. Adding function-body ownership to already decoded instructions is distinct from adding instructions to the global listing.

The first broad-disassembly prototype added 2,876 instructions in 22 unrelated intervals and was rejected. `broad-disassembly-superseded.json` retains that failure. The subsequent pair-only full export retained the known `0017f510` decompilation failure because the pristine copied project did not persist its previous read-only override; `pair-only-superseded.json` records this. The final combined run applied all three overrides explicitly. Earlier failed construction/delay-slot attempts remain in the independent private receipts referenced by the provenance record.

Jev verified the root containment and changed-file claims; the independent review's low-confidence outcomes and failed equivalence claims remain in the reproducibility receipt. These static reconstructions do not prove dispatch reachability, an original source switch, general native-patch correctness, or whole-game equivalence. Full generated game C and raw inventories remain ignored scratch. This bundle records bounded metadata, hashes, exact commands, validation results, and preserved failures.
