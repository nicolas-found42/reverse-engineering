# Packed-register shuffle corrections

The pinned PS2Recomp translator used incorrect word permutations for three instructions present in the byte-verified game inventory: PEXEW (26 sites), PEXCW (2), and PROT3W (157). Counts identify static instruction sites; they do not establish that the game executes them.

Numbering four 32-bit words from low to high, the required source indices are PEXEW `[2,1,0,3]`, PEXCW `[0,2,1,3]`, and PROT3W `[1,2,0,3]`. These follow the explicit Operation assignments in Sony's [EE Core Instruction Set Manual v6.0](https://docs.alexrp.com/mips/ee_insns.pdf), PDF pages 201, 199, and 260. The pinned [PCSX2 implementation](https://github.com/PCSX2/pcsx2/blob/81526d4dc7cc70e4ae75abb35a789417456c6d43/pcsx2/MMI.cpp) independently agrees. The fix updates the PEXEW and PROT3W runtime macros and the emitted PROT3W/PEXCW templates. It preserves the fourth word for each operation.

`tools/recomp/verify_shuffles.py` rejects altered upstream source or patch hashes, constructs exact candidate sources, and compiles the extracted production templates/macros with undefined-behavior sanitizers. The probe checks four distinct lane basis vectors and 10,000 seeded random vectors, each with separate source/destination, in-place destination/source aliasing, source register zero, and destination register zero. Each of four tested paths (three emitted operations and the additional PROT3W macro) performs 40,016 comparisons. The original source remains a required negative control and produces mismatches for every path; the corrected source produces none. No original game function executes.

The promoted verifier passed its native probe, four source-guard tests, and pyright with zero errors/warnings. The earlier build failed because `-Werror` also covered existing unused parameters in the third-party SSE2NEON header. That failure is retained. The corrected invocation marks that dependency as a system include while preserving warnings-as-errors for the probe.

Jev's patch review escalated at safe-to-apply 0.53, with low blast-radius confidence. The PCSX2 source screen also requested review at injection probability 0.58. Independent inspection found ordinary register assignments and runtime aliasing comments, with no directions to an agent; the source was used only as a static implementation reference. The exact outcomes and argument digests are preserved in `jev-results.json`, and complete input receipts remain at the recorded scratch paths. Neither outcome is presented as automatic approval. The deterministic native controls and independent review support only this bounded correction; full translator semantics, silicon behavior, game reachability, and whole-game equivalence remain unproved.
