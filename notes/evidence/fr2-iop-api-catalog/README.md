# Provisional IOP API-name catalog

The 24 measured IRX modules contain 748 import stubs. A source-pinned public SDK catalog supplies 436 provisional API names using exact library name, full version, and ordinal matches. The other 312 imports remain unresolved. These annotations do not claim original function names, the game's exact linked SDK revision, or API implementation equivalence.

`tools/ps2_irx_catalog.py` reads literal export macro declarations from [PS2SDK commit ac92a9f657d2e531dd8f060250b07f2a5ac6dea5](https://github.com/ps2dev/ps2sdk/tree/ac92a9f657d2e531dd8f060250b07f2a5ac6dea5). It verifies checkout HEAD and compares all 83 tracked `exports.tab` files to the pinned Git objects before reading declarations. Source hashes are retained. Fourteen files with preprocessor-dependent or unsupported declarations are excluded rather than choosing a build variant; the remaining files produce 77 table records. Source helper C outside tables is never evaluated. No SDK preprocessing, compilation, loading, or machine-code execution occurs.

Ordinal zero is the first declared function, including reserved entries. Full version equality is deliberately stricter than broad ABI-compatibility assumptions. Conflicting exact-version table names remain ambiguous; agreeing tables retain every matching source. Each annotated name carries `original_identity_verified=false`. An unresolved import can reflect a version mismatch, absent catalog library, missing ordinal, or a deliberately excluded conditional table. The annotations do not mutate the raw import parser or Ghidra projects.

The initial seven focused tests cover comment decoys that would shift ordinals, unsupported conditional exports, invalid/nested/unterminated declarations, exact minor-version mismatch, absent ordinals, conflicting/agreeing tables, and bounded version/index domains. They passed, and pyright reported zero errors and warnings. The earlier missing-module test is preserved as the initial red result. A CLI run against the private STREAM module produced only candidate metadata in fresh output. The full corpus receipts contain hashes and annotations, with no module payload or generated game code.

`catalog.json` records source files, exclusions, table versions and declared names. `module-annotations.json` records every import tuple and its candidate status. The source is [PS2SDK's IOP export declarations](https://github.com/ps2dev/ps2sdk/blob/ac92a9f657d2e531dd8f060250b07f2a5ac6dea5/iop/system/threadman/src/exports.tab); PS2SDK is published under the [Academic Free License 2.0](https://github.com/ps2dev/ps2sdk/blob/ac92a9f657d2e531dd8f060250b07f2a5ac6dea5/LICENSE). This bundle extracts factual table names/ordinals and provenance; it does not include the SDK implementation.

Firecrawl fetched the pinned thread-manager export declarations. Jev's combined export-source screen requested review at injection probability 0.28. Root inspected the inert declarations and the one runtime-use comment, found no agent-directed instructions, and retained the review receipt and manual disposition. The tool's narrow literal grammar excludes comments and all files containing preprocessing directives. Subsequent review and factual verification receipts are preserved separately; none establishes original identity or the game's runtime linking result.

Independent review identified a hexadecimal-version coverage gap. That conditional SDK file remains excluded; this tool supports only plain decimal version literals. Root also added a failing regression for octal-looking leading-zero literals, which the initial decimal regex misinterpreted. The grammar now accepts only `0` or a nonzero digit followed by at most two decimal digits, and rejects hexadecimal, octal-looking, and oversized fields. All eight focused tests pass, pyright remains clean, and the complete pinned catalog hash is unchanged. The original red/green logs are preserved.
