# Geometry record endpoint pairs and corner construction

The loader-derived 52-byte geometry table contains three finite, ordered endpoint pairs at serialized offsets `+4/+8`, `+12/+16` and `+20/+24`. The [archive-bound corpus receipt](corpus-result.json) measures all 16,074 records in 56 exact-EOF models: 96,444 endpoint words, zero nonfinite words, zero reversed pairs and 56 entirely zero records. The 54 loader68 and two SHA-bound measured legacy60 profiles remain distinguished. This is a bounded geometry invariant; vertex containment, units, plane semantics and rendering remain unresolved.

`FUN_0011ed90` stores the table base in resource context `+0x14`. `FUN_0021b710` resolves the low 16 bits of an ID into that table with stride `0x34` and rejects ID zero. It selects the resource context using bits 20–23 and stride `0x114`. The previously inspected name/object resolver `FUN_001213d8` instead addresses a separate `0x58` table; those record families must not be conflated.

`FUN_00122d90` calls the geometry resolver at `00122da0`. A taken branch-likely delay slot at `00122dac` advances the returned pointer by four bytes. Its loads from that shifted pointer at offsets `0,4,8,12,16,20` therefore read serialized offsets `4,8,12,16,20,24`. Packed `PEXTLW`/`PCPYLD` operations (`pextlw` in the instruction listing) create eight four-word vectors with one choice from each adjacent pair and homogeneous word `1.0`. The [symbolic packing checker](check_corner_provenance.py) validates all 204 instruction words of the resolver and consumer against the original executable and reconstructs all eight combinations. [Its output](corner-provenance.json) gives source offsets and instruction-byte hashes, without retaining full game code. It does not execute original instructions or evaluate VU arithmetic. The following VU operations transform those vectors and reduce six output extrema, but their numerical equivalence is not established here.

An initial exploratory interpretation treated the six words as two triplets. That produced 15,805 records with at least one reversed pair and is retained in [the superseded hypothesis](superseded-triplet-hypothesis.json). Exact load and packed-lane inspection establishes the adjacent pair selection. This correction was made before adding the verifier. The first symbolic checker also rejected a second `lui` in the bounded packing span because its whitelist expected only the homogeneous-word constant; the second `lui` initializes the later matrix address after the relevant word has been packed. The checker now explicitly accepts that address setup. This was an observation-model error, not a change to game instructions.

[Five focused tests](focused-tests.log) check every endpoint with NaN and both infinity encodings, reverse each pair independently, accept degenerate and signed-zero pairs, and reject malformed table counts, strides and bounds. [Two real-asset controls](real-asset-negative-controls.json) mutate only in-memory copies of `49COUPE.PS2;1`: one NaN endpoint and one reversed pair are each detected while the original file hash remains unchanged. [Pyright](pyright.log) reports zero errors. The current [full Python suite](full-python-suite.log) passes 284 tests in 46.631 seconds, including the concurrently added multiply checks. The initial missing-module test failure is preserved in [red.log](red.log).

Jgrep was used for two distinct local behaviors. The initial name-resolution query returned no matches; a query scoped to 44 name-resolver callers returned 18 candidate ranges, whose metadata and excerpt hashes are in [jgrep-object-query.json](jgrep-object-query.json). Those lead to the separate object table. A later query scoped to 12 actual geometry-resolver users returned no matches for the corner construction. A semantic-search miss does not refute the exact instruction trace.

[Jev r077](r077-claim-verification.json) verifies the packing and corpus statements at confidence 0.97 and rejects the broad geometry-completion claim as unsupported (relation contradicted). [Jev r078](r078-verifier-gate.json) remains escalated at `safe_to_apply` 0.32, with test-gap and confidence limits. It verifies the byte/symbolic claim but calls the test-pass statement unsupported at 0.41 despite the provided logs. Both receipts remain unchanged. Root directly checked the exit statuses, exact logs, fresh corpus receipt, ELF words and in-memory controls. The bounded verifier is retained as experimental measurement tooling; the judgment is not approval or evidence of full geometry recovery.
