# Runtime link-check preflight

This folder records a link-only integration plan for the existing FPU-patched FR2 function objects against the pinned PS2Recomp runtime. It is not a product patch or a headless runtime implementation. No target link was possible during this pass because CMake and the raylib source/header/library are absent from the available local environment.

The generated objects are native Mach-O arm64 and already include the registration object. When prerequisites are available, use the pinned clone at `.scratch/mesh/codex-root/PS2Recomp-fpu-01` and configure an isolated out-of-tree runtime build with recompiler, analyzer, tests, and studio disabled; runtime enabled; debug UI disabled; and `PS2X_ENABLE_FFMPEG=OFF`. Keep FetchContent disconnected and point it at an already-local raylib 5.5 source tree. The runtime's `ps2_host_backend.h` includes `raylib.h`, and CMake links raylib even with debug UI off, so no raylib-less headless build is evidenced.

For the link-only target, add the existing 17 generated object files as external object sources to `ps2EntryRunner` (or otherwise use a platform-supported whole-archive/group strategy) so the generated table globals and functions are present before the static `ps2_runtime` archive resolves its runtime-method references. Passing only the generated static archive after `ps2_runtime` could leave a static-library reference cycle: runtime code references the generated table, while generated functions reference `PS2Runtime` methods. The object-source approach avoids that archive ordering ambiguity. Build `ps2EntryRunner` only; never launch it. A successful link would establish only link compatibility for this source/toolchain configuration, not game behavior or runnable completeness.

Before any such link, require a local CMake executable, a local raylib source tree/header, and the matching AppleClang/arm64 host SDK. This audit made no downloaded dependency or system change and did not create invented stubs to satisfy unresolved names. Exact preflight failures are in `notes/evidence/fr2-link-interface-audit/build/README.md`.
