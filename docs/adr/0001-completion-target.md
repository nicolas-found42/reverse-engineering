# Completion target: byte-exact matching rebuild of the whole PAL corpus

The owner named "the entire game fully reverse engineered" as the goal, which is not a testable finish line, and the project rule is that a broader effort needs a named, measurable bar. Decided: the target is a **byte-exact matching rebuild** — a source tree that compiles with the corpus's own toolchain and reproduces the retail ELF byte for byte under an ELF-hash gate — covering the **whole corpus**: the EE executable, all 24 IOP IRX modules, the eight VU microprograms, and every asset grammar. Code is bar'd by reconstruction (types, signatures, boundaries) and, where a compiler is pinned, by byte match; VU and assets carry a reconstruction + documented-consumer-contract bar because **no static decompiler for VU exists in any public tool**. Every stage keeps an explicit unresolved list.

Considered and rejected: **readable reconstruction** (compiles, structurally faithful, not byte-exact — rejected, the owner chose byte-exact); **host-runnable port** (execute recovered logic and play it — rejected).

Headless, focus-free execution is permitted as a behavioral oracle (see [ADR-0002](0002-headless-execution-permitted.md)); this supersedes the earlier "static and offline only" rule. All tooling and code must be open source ([ADR-0003](0003-open-source-only.md)). The corpus is never committed.

**Per-subsystem bars.** The EE/IOP core is bar'd by byte match. VU is bar'd by byte-exact **reassembly** from recovered assembly (`dvp-as`, the eight chunks already reassemble) plus a documented entry map from its MSCAL callers — byte-exact VU **C** is out of scope. Assets are bar'd by a documented consumer contract per type. A matching rebuild requires **zero unmatched game-owned bytes**; a documented **unresolved list** (one reason and one falsifier per item) may remain at 100%, but nothing approximately matched is ever counted as matched.

**Toolchain (measured 2026-10-05).** FR2's game code was built with a **Sony/Cygnus GNU `ee-gcc`/`ee-as`**, not a proprietary compiler — evidence: `sd`/`ld` callee-saved spills (~15:1 over `sq`/`lq`), and GNU `as` short-loop behaviour (no SN `ps2eeas` padding; FP compare directly adjacent to `bc1`), plus libgcc's `__clz_tab` and no `Metrowerks`/`SN Systems`/`ProDG` strings. SDK libraries are ≈ 2.5.5. The **exact `ee-gcc` id is not yet pinned** and must be determined by compile-and-diff under the `decompme/compilers` PS2 ids; this does not change the target. See `notes/research/fr2-toolchain-identification.md`.
