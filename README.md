# Ford Racing 2 reverse engineering

Notes and tools for reverse engineering the PlayStation 2 version of *Ford Racing 2*.

The repository contains analysis notes and scripts. Game media, extracted assets,
Ghidra project state, downloaded tools, and scratch files remain local and are
excluded from version control.

Issues and project maps are tracked in GitHub Issues. See [`docs/agents/issue-tracker.md`](docs/agents/issue-tracker.md).
